# 🌤️ Weather App

A simple and responsive weather app that allows users to check **current weather conditions** in **English** and using **metric units** (°C, km/h, etc.).

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays temperature in Celsius
- 🌬️ Shows wind speed in mph
- 🌍 Uses English language for all info
- 📱 Responsive design for mobile and desktop

## 🛠️ Built With

- **HTML**
- **CSS**
- **JavaScript**
- Weather API (e.g., OpenWeatherMap or similar)
